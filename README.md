# カブぐらし — 2年間の投資家生活

Cloud Storageで配信できる、ビルド不要の静的ゲームです。公開対象は `site/`。ゲーム処理と保存はブラウザ内で完結します。

## 起動・検証

- `node scripts/serve.cjs` を実行し、http://127.0.0.1:8080 を開く。
- `node --test tests/engine.test.cjs` でゲームロジックを検証。
- `node tests/browser.cjs` でPlaywrightによる画面操作を検証。Playwrightを用意し、必要に応じて `NODE_PATH` を設定する。`KABU_BROWSER` はChrome等の実行ファイル、`KABU_SCREENSHOTS` は画像出力先。

## 基本ルール

初期資金100万円。24か月、毎月2回、計48回の行動。前半行動 → 後半行動 → 月末売買 → 月末決算で進む。売買は100株単位・行動コスト0。会社員、トレーダー、インフルエンサー、資産家のいずれかを目指し、行動と実績で能力を育てる。

半年ごとの期限目標は200万、500万、1,200万、3,000万円。期限の月末総資産で判定し、未達ならその場で終了。最終目標を突破するとクリア。中間目標の報酬は追加資金、配当倍率＋0.20、毎月の調査pt＋2から選択する。

## 予定と調査pt（v3）

各銘柄は4〜5個の事業タグを持つ。イベントのタグが1個でも一致すれば対象になり、複数一致した銘柄にも値動きは1回分を適用する。

| 銘柄 | 事業タグ |
| --- | --- |
| ミライチップ | 半導体・AI・研究開発・データセンター・海外展開 |
| ピクセルクエスト | ゲーム・エンタメ・サブスク・海外展開 |
| ひだまり銀行 | 銀行・決済・地域経済・資産運用 |
| そらクラウド | IT・AI・データセンター・サブスク・決済 |
| ドラゴンバイオ | 医療・AI・研究開発・海外展開 |
| まちのマート | 生活・決済・地域経済・海外展開 |

単一業種のニュース、共有タグによる横断ニュース、複数タグを持つ広いニュースを混在させる。例えば「決済」は銀行・クラウド・小売、「サブスク」はゲーム・クラウドに影響する。

- 予定欄は4枠。各予定は1〜3か月後に決着する。初期枠には当月決着の単発予定と連続イベントを含む。
- 「あと1か月」は今月末。「あと3か月」は今月を含む3回目の月末。例：1月に追加された3か月予定は3月末に判定する。
- 期日前の予定は同じID・期限・調査状態で持ち越す。決着した予定を取り除き、翌月の開始時に新しい予定を補充する。
- 基本成功率は30〜90%。連続イベントと発信の補正を含む実効成功率は30〜99%。
- 値動きは基本成功率を基準に設定する。発信や連続イベントによる成功率の上昇は、その予定の上昇幅・下落幅を保ったまま投資の見込みを改善する。
- 全予定が成功時の上昇率と失敗時の下落率を持つ。独立した下落ニュースと別枠の突発ニュースは統合済み。
- 初期調査ptは3。情報収集は1行動で基本3pt獲得。ptの消費は行動期間・月末ともに可能で、行動コスト0。残高は翌月に持ち越す。
- 未調査の予定は残り月数だけを表示。1ptでタイトル・タグ、続いて2ptで成功時/失敗時の値動き、さらに3ptで成功率が判明する。1予定を全開示する費用は合計6pt。
- 知識や人脈はptの獲得量に影響する。知識2ごとに情報収集の獲得量＋1pt、人脈3ごとに翌月から毎月＋1pt。
- トレーダーは情報収集の獲得量＋1ptから開始。情報収集3回/6回で成長し、さらに各＋1pt。
- インフルエンサーは月末に、タグを調べた予定を1件応援できる。成功率への加算は10/15/20ポイント、上限99%。発信効果はその予定の決着まで持続し、同じ段階への発信は1回。
- 「情報の目利き」は段階調査4回で達成し、情報収集の獲得量＋1pt。「学びを武器に」は勉強3回で助成15万円と獲得量＋1pt。「顔の広い投資家」は交流3回で毎月＋1pt。
- 記者イベント完走は15万円と毎月＋2pt。目標の情報網報酬は毎月＋2ptに加え、選択時にも2ptを受け取る。

## 連続イベント

### 値動きの初期設定（単発・連続の各段階を含む）

| 基本成功率 | 成功時の上昇幅 | 失敗時の下落幅 |
| --- | --- | --- |
| 90% | +8〜12% | −25〜38% |
| 80% | +15〜18% | −25〜38% |
| 70% | +25〜35% | −22〜35% |
| 60% | +40〜50% | −25〜45% |
| 50% | +60〜85% | −18〜55% |
| 40% | +90〜110% | −18〜50% |
| 30% | +140〜200% | −15〜60% |

同じ確率でも事業内容に応じて値動きを変える。例えば30%の新素材研究は+140%/−15%、新薬治験は+200%/−60%。

企業計画も通常の4枠に登場する。タグ調査で「連続イベント」と現在の段階数が分かる。標準データには6種類の3段階計画があり、各段階の期間は1/2/2か月。

段階の決着後は、同じ計画の次段階を新しい予定IDで追加する。調べたタグを引き継ぎ、値動きと成功率は新しい段階で再調査する。前段階の成功で次段階の見込み＋10ポイント、失敗で−10ポイント（累積補正は±25以内）。各段階は成功・失敗のどちらでも次へ進む。

最終成功で対象株の月次配当利回り＋1ポイント（上限20%）。3段階の決着時に2回以上対象株を保有し、最終判定にも保有していれば、その時点の対象保有時価の4%を追加獲得する。

人との出会いによる個人イベントは別の行動として継続。各3行動で完走すると報酬を受け取る。未来の出会い・報酬は、プレイ中に順に明らかになる。

## 月末・保存・演出

月末は「期日を迎えた予定 → 配当と実績 → 期限目標判定 → 継続時は新しい予定の補充・人脈pt」の順。配当はイベント後の株価で計算する。複数の予定が同じ株に影響すると、予定の表示順で倍率を適用する。

v3の保存キーは `kabugurashi-plans-v3:` とURLパスの組み合わせ。以前の1年版・2年版の保存は別キーに保管され、新仕様は新しい挑戦から始まる。予定ID・期限・調査段階・pt・発信・乱数状態まで保存する。

予定の確率・上昇幅・下落幅だけの調整時は、v3の保存を継続して利用できる。未決着の予定に新しい設定を適用し、過去の資産や結果はそのまま保持する。

事業タグ・企業概要・イベントの文面の更新も同様に保存を継続できる。銘柄IDや並び順、イベント段階の期間などの構造は互換性の判定に使用する。

演出の前に結果を確定・保存する。スキップは表示の切り替えだけを行う。効果音と演出の長さは設定で変更できる。操作に必要なコストと期限を画面に残し、能力の詳しい効果は達成時の演出と「見つけた強み」で表示する。

## 構成

- `site/engine.js`：進行・売買・予定・調査pt・報酬・保存検証。`planView` が調査済み情報だけを画面に渡す。
- `site/game.js`：画面と操作。`site/presentation.js`：行動・会話・ニュース演出。`site/boot.js`：データ読み込み。
- `site/data/config.json`：期間、目標、初期pt、段階調査コスト。
- `site/data/events.json`：予定ごとのタグと各段階の期間・成功率・成功/失敗時の値動き。
- `site/data/companies.json`：銘柄と初期株価・配当。

目標額、pt量、報酬、確率は調整用の初期値。公開は既存のGitHub Actionsから `site/` をCloud Storageへ同期する。
